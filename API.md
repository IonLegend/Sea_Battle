# 🎯 Полный список API библиотеки SeaBattle

⚠️ **Важно!** Не рекомендуется использовать методы, начинающиеся с `_`. Это может нарушить логику библиотеки и сломать всю внутреннюю систему.

---

## 🏗️ Класс `Field`

### 🎮 Инициализация

| Метод | Описание |
|-------|----------|
| `Field()` | Создает новое игровое поле 10×10 |

### 🖥️ Отображение

| Метод | Возврат | Описание |
|-------|---------|----------|
| `display()` | `None` | Печатает поле в консоль с кораблями |
| `display_clear()` | `None` | Печатает поле в консоль без кораблей (скрывает '1') |
| `custom_display(theme_document: str, hide_ships: bool)` | `None` | Отображает поле с цветами из JSON-конфигурации |

### 📊 Get-методы для поля

| Метод | Возврат | Описание |
|-------|---------|----------|
| `get_grid(hide_ships: bool)` | `list[list[str]]` | Возвращает копию сетки 10×10. При `hide_ships=True` заменяет '1' на ' ' |
| `get_ship_information()` | `list[dict]` | Возвращает информацию по всем кораблям (ID, живые клетки, раненые, буфер) |
| `get_statistics()` | `dict` | Возвращает статистику поля (оставшиеся корабли, длины, выстрелы, доступные клетки) |

### ✅ Валидация

| Метод | Возврат | Описание |
|-------|---------|----------|
| `validation_coordinate(coordinate: str)` | `bool` | Проверяет валидность координаты (формат 'a1'..'j10') |
| `_validation_coordinate_log(coordinate: str)` | `bool` | Проверяет валидность с подробным выводом ошибок в консоль |

### 📍 Работа с координатами

| Метод | Возврат | Описание |
|-------|---------|----------|
| `cell_state(coordinate: str)` | `str \| None` | Возвращает состояние клетки: 'clear', 'ship', 'hitted', 'destroyed', 'was_beaten' |
| `coord_to_index(coordinate: str)` | `tuple[int, int]` | Преобразует координату в индексы (строка, столбец) для доступа к grid |
| `index_to_coord(x: int, y: int)` | `str \| None` | Преобразует индексы обратно в координату |
| `get_neighbours(coordinate: str)` | `list[str]` | Возвращает список соседних клеток |
| `get_available_cells()` | `list[str]` | Возвращает доступные для постановки корабля клетки |
| `get_all_cells()` | `list[str]` | Возвращает все клетки поля |

### 🚢 Работа с кораблями

| Метод | Возврат | Описание |
|-------|---------|----------|
| `get_ship_name(length: int)` | `str` | Возвращает название корабля по длине (1→Speedboat⚡, 2→Destroyer🔫, 3→Cruiser🚀, 4→Battleship⚓) |
| `can_place_ship(coordinate_line: str, length: int)` | `bool` | Проверяет, можно ли поставить корабль на указанную линию |
| `auto_add_ship(coordinate_line: str, length: int)` | `bool` | Добавляет корабль на поле. Создает буфер, обновляет запрещенные/доступные клетки |
| `replace_ship(coordinate_line_from: str, coordinate_line_to: str)` | `bool` | Перемещает корабль на новую позицию, сохраняя ID |
| `delete_ship(coordinate_line: str)` | `bool` | Удаляет корабль с поля |
| `shot(coordinate: str)` | `str` | Производит выстрел. Возвращает: 'Blunder', 'Hit', 'Target destroyed', 'Invalid shot', 'Was beaten' |
| `random_placing()` | `bool` | Автоматическая расстановка всех кораблей (10 штук) 🎲 |
| `find_from_id(id)` | `Ship \| None` | Возвращает корабль по ID или None |

### 🎯 Логика для игры

| Метод | Возврат | Описание |
|-------|---------|----------|
| `is_game_over()` | `bool` | Проверяет конец игры (`True` — игра окончена, все корабли уничтожены) 🏆 |
| `get_shots_history()` | `list` | Возвращает историю выстрелов 📜 |
| `get_remaining_ships_lengths()` | `list[int]` | Возвращает длины всех оставшихся (не уничтоженных) кораблей |
| `field_game_reset()` | `None` | Очищает доску и удаляет все корабли 🔄 |

### 💾 Сохранение и загрузка

| Метод | Возврат | Описание |
|-------|---------|----------|
| `save(filename: str)` | `bool` | Сохраняет состояние поля в JSON-файл 💾 |
| `load(filename: str)` | `Field \| None` | Класс-метод. Загружает поле из JSON-файла 📂 |

## ⛵ Класс `Ship`

### 🏗️ Инициализация

| Метод | Описание |
|-------|----------|
| `Ship()` | Создает новый корабль со случайным ID (1-1000) |

### ⚙️ Работа с параметрами

| Метод | Возврат | Описание |
|-------|---------|----------|
| `_set_field(field)` | `None` | Привязывает корабль к полю |
| `display_parameters()` | `None` | Выводит параметры корабля в консоль 📋 |

### 🎯 Логика для игры

| Метод | Возврат | Описание |
|-------|---------|----------|
| `get_died_coordinate()` | `list` | Возвращает список уничтоженных (раненых) координат 💀 |
| `get_id()` | `int` | Возвращает ID корабля 🆔 |
| `get_parameters()` | `dict` | Возвращает полный словарь параметров корабля 📦 |

## 📌 Константы

### 🧩 Состояния клеток

| Константа | Значение | Описание | Эмодзи |
|-----------|----------|----------|--------|
| `CLEAR` | `' '` | Пустая клетка | 🌊 |
| `HITTED` | `'x'` | Попадание (корабль ранен) | 💥 |
| `DESTROYED` | `'X'` | Корабль уничтожен | 💀 |
| `SHIP` | `'1'` | Живой корабль | 🚢 |
| `WAS_BEATEN` | `'.'` | Промах (клетка обстреляна) | ⭕ |

### 🎯 Результаты выстрелов

| Константа | Значение | Эмодзи |
|-----------|----------|--------|
| `SHOT_MISS` | `'Blunder'` | ❌ |
| `SHOT_HIT` | `'Hit'` | 💥 |
| `SHOT_KILL` | `'Target destroyed'` | 💀 |
| `SHOT_WAS_BEATEN` | `'Was beaten'` | 🔄 |
| `SHOT_ERROR` | `'Invalid shot'` | ⚠️ |

### ⚓ Флот

| Константа | Значение |
|-----------|----------|
| `FLEET_LENGTHS` | `[4, 3, 3, 2, 2, 2, 1, 1, 1, 1]` |

## 📝 Пример использования

```python
# Создание поля
field = Field() 🎮

# Автоматическая расстановка
field.random_placing() 🎲

# Отображение
field.display() 🖥️

# Выстрел
result = field.shot('a1') 🎯
print(result)  # Hit / Miss / Target destroyed

# Проверка окончания игры
if field.is_game_over(): 🏆
    print("Game Over!")

# Сохранение
field.save('save.json') 💾

# Загрузка
loaded_field = Field.load('save.json') 📂
```
